
# Capital Bikeshare Ride Analysis (2024)

## Project Overview

This project analyzes 862,444 Capital Bikeshare trips in Washington, D.C., to identify ridership trends, station usage patterns, and rider behavior.

The goal is to understand how people use the bike-sharing system and identify opportunities to improve bike availability, station utilization, and operational planning.

## Business Questions

- Which stations have the highest and lowest ride activity?
- What days and hours experience the highest ridership?
- How does ridership differ between members and casual riders?
- What is the typical trip duration?
- How much activity comes from the 20 least-used stations?

## Tools & Technologies

- Python
- Pandas
- Plotly Express
- Jupyter Notebook
- Data Visualization
- Exploratory Data Analysis

## Key Findings

- Analyzed 862,444 bike rides across 13 columns.
- Friday was the busiest day, with approximately 149,000 rides.
- Monday was the least busy day, with approximately 102,000 rides.
- 5:00 PM was the most common rental start hour.
- Average trip duration was approximately 18.3 minutes.
- Median trip duration was 10 minutes.
- The 20 least-used starting stations accounted for approximately 0.012% of all rides.

## Recommendations

1. Use peak ridership patterns to improve bike distribution and availability.
2. Investigate low-usage stations to understand whether location or awareness contributes to limited activity.
3. Encourage casual riders to explore membership options.
4. Use trip-duration trends to support maintenance and operational planning.

## Limitations

Some station information is missing, which may affect station-level comparisons. However, these rides can still be included in analyses of trip duration, day, and rider type.

Low station usage alone does not establish that a station should be relocated.
